EduInsight Demo Walkthrough

Follow the steps below to experience the AI learning assistant with memory-augmented personalization and learning analytics.

First, load demo data — 4 students with realistic learning histories.

1
Meet the Demo Students
▶

The demo includes 4 students, each with a different learning profile and history:

Student 1001
Struggling with data structures. Asks many questions about linked lists, trees, and hash tables. Prefers visual explanations.
Data Structures
Student 1002
Advanced student. Focuses on algorithm analysis — DP, graph algorithms, complexity theory. Prefers formal proofs.
Algorithms
Student 1003
Beginner programmer. Learning Python basics — loops, scope, error handling. Learns best from simple code examples.
Python Programming
Student 1004
Database enthusiast. Studies normalization, SQL queries, ACID. Prefers real-world examples tied to practical design.
Database Systems
2
Teacher Dashboard — View Learning Analytics
▶

Open the Teacher Dashboard to see an overview of all students, their memory counts, and topic categories. Click on any student to view their stored memories.

What to look for: Each student has different memory categories reflecting their unique learning focus. The dashboard shows total memories, categories, and last activity time.
Open Teacher Dashboard →
3
Student Chat — Memory-Aware Conversations
▶

Open the student chat and set Student ID = 1001. Ask a question related to their history. The AI will use their stored memories to personalize the response.

Key feature: Click "Memory context used" on any response to see which memories the system retrieved to personalize the answer.

Try these questions as Student 1001:

  • → How do I implement a binary search tree?
  • → What is the time complexity of hash table operations?

Now try as Student 1003 (beginner):

  • → How do I write a function in Python?
  • → What is a dictionary?
Note: If no LLM API key (GEMINI_API_KEY) is configured, the chat will show memory context only without AI-generated answers. The memory retrieval still works.
Open Student Chat →
4
Observe Memory Growth
▶

After chatting with a student, go back to the Teacher Dashboard and refresh. You'll see:

  • Memory count increased for the student you chatted as
  • New memories stored from the conversation
  • Updated "Last Active" timestamp
This demonstrates the core value: Every student interaction automatically builds a learning profile that teachers can observe and AI can use for personalization — no manual tagging required.
5
Compare Personalization
▶

Ask the same question to two different students and observe how the memory context (and AI response if LLM is configured) differs:

  • → Student 1001: "Explain Big O notation"
  • → Student 1002: "Explain Big O notation"
Notice: Student 1001 (who struggles with complexity analysis) will get simpler context. Student 1002 (who prefers formal analysis) will get advanced context like amortized analysis references.
