## 一、作品名稱與摘要

**作品名稱**：EduInsight — 具持久記憶的 AI 學習助教平台

**摘要**：EduInsight 是一套整合 Moodle LMS 的 AI 學習助教系統，核心創新在於導入持久性學生記憶機制。不同於現有 AI 教育工具僅能在單次對話中回應學生，EduInsight 透過自主研發的記憶引擎 Lite-Mem，自動擷取並累積每位學生的學習歷程（提問主題、理解困難、學習偏好），使 AI 能跨對話、跨時間地記住每位學生，提供真正個人化的學習輔導。教師端則可透過學習分析儀表板，即時掌握全班與個別學生的學習狀態，實現數據驅動的教學決策。

### 2.2 核心技術模組

| 模組 | 技術 | 說明 |
|------|------|------|
| 後端框架 | FastAPI (Python 3.12) | 非同步 REST API，支援 LTI 1.3 協議 |
| 記憶引擎 | Lite-Mem (自主研發) | SQLite + FTS5 全文搜尋 + 向量語意搜尋 |
| LLM 整合 | OpenAI-compatible API | 可插拔式 LLM 後端（Gemini、GPT、Groq、Claude、Ollama） |
| LMS 整合 | Moodle Web Services + LTI 1.3 | 標準協議，不修改 Moodle 核心 |
| 前端介面 | HTML/CSS/JS (SPA) | 深色主題、響應式設計，嵌入 Moodle iframe |
| 事實擷取 | Lite-Mem Extractor | 自動從對話中提取結構化學習事實 |

### 2.3 AI 記憶機制（核心創新）

EduInsight 的記憶機制分為三層：

1. **記錄層**：每次對話自動記錄學生提問的主題、內容與 AI 回應。
2. **擷取層**：透過 Lite-Mem 的事實擷取器（Extractor），自動從對話歷史中抽取結構化事實，如「學生在遞迴概念上有困難」、「偏好以圖解方式學習」。
3. **應用層**：下次對話時，系統自動檢索相關記憶，將學生的學習脈絡注入 LLM 提示詞，使 AI 能延續先前的教學策略。

**與傳統方案的差異**：

| 項目 | 傳統 AI 聊天機器人 | EduInsight |
|------|-------------------|------------|
| 記憶範圍 | 單次對話 | 跨對話、跨學期 |
| 學生模型 | 無 | 自動建構（困難點、偏好、進度） |
| 個人化程度 | 僅限當次對話 | 基於完整學習歷程 |
| 教師洞察 | 無 | 即時學習分析儀表板 |

## 三、功能說明

### 3.1 學生端：智慧對話助教

- **記憶增強回應**：AI 根據學生過往學習記錄，調整回答深度與方式。例如，已知學生在「指標」概念有困難，回答資料結構問題時會避免直接使用指標術語，改用圖解說明。
- **Markdown 渲染**：支援程式碼區塊、表格、數學公式等豐富格式。
- **記憶上下文透明化**：每則回應可展開檢視 AI 參考了哪些記憶，確保可解釋性。
- **Moodle 無縫整合**：透過 LTI 1.3 直接嵌入 Moodle 課程頁面，學生無需另外登入。

### 3.2 教師端：學習分析儀表板

- **全班統計總覽**：學生人數、總記憶數、平均每人記憶數。
- **學生列表與分類**：按最近活躍度排序，顯示每位學生的記憶數量與類別（困難/偏好/一般）。
- **個別學生記憶檢視**：點擊學生可查看所有儲存的記憶，了解學習軌跡。
- **班級困難排行**：自動彙整全班共同困難主題，協助教師調整教學重點。

### 3.3 學習軌跡分析

- **時間序列分析**：以週為單位追蹤學生的記憶累積、新困難點、主題分佈變化。
- **學習趨勢視覺化**：長條圖呈現每週記憶成長與困難點數量。
- **學期歷程展示**：支援 18 週學期模擬，展示從基礎到進階的完整學習弧線。

### 3.4 記憶可攜性

- **匯出/匯入**：支援以標準 JSON 格式匯出學生記憶，可跨系統遷移。
- **隱私保護**：記憶資料完全存放於自架伺服器，不上傳至第三方雲端。

## 四、創新性與競品分析

### 4.1 教育 AI 現有方案與限制

| 現有方案 | 特色 | 限制 |
|---------|------|------|
| Moodle 5 內建 AI | 摘要/解釋/生成 | 無學生歷史追蹤 |
| block_ai_chat | 完整對話 UI | 無跨對話記憶 |
| LearnWise AI | AI 輔導+批改 | SaaS 付費、無記憶持久性 |
| Raison (Corolair) | 課程內容 → AI | 無跨對話記憶 |
| Inspire Analytics | ML 學習分析 | 非 AI 聊天機器人 |

### 4.2 EduInsight 的差異化創新

1. **持久記憶**：業界首個將跨對話記憶持久化應用於 LMS 整合的開源方案。自動事實擷取免去人工標註，記憶隨使用自然累積。
2. **混合搜尋**：結合 FTS5 全文搜尋（關鍵字匹配）與向量語意搜尋（60% 餘弦相似度 + 40% FTS5），在記憶檢索時兼顧精確性與語意理解。
3. **LLM 不綁定**：可插拔式 LLM 後端，支援 Gemini、GPT、Groq、Claude、Ollama 等，學校可依預算與隱私需求自由選擇。
4. **標準協議整合**：透過 LTI 1.3 與 Moodle Web Services API 整合，不修改 Moodle 核心，適用於任何支援 LTI 的 LMS。
5. **完全開源**：MIT 授權，學校可自行部署、客製化，無 SaaS 鎖定。

## 五、實用性與可行性

### 5.1 部署方案

- **單機部署**：`uv sync && uv run uvicorn eduinsight.app:app` 即可啟動，適合試用與小規模部署。
- **Docker 部署**：提供 Docker Compose 配置，包含 Moodle + EduInsight 完整開發環境。
- **LMS 整合**：管理員只需在 Moodle 新增 LTI 1.3 外部工具，填入 EduInsight 的 URL 即可完成串接。

### 5.2 適用場景

- **大學程式設計課程**：追蹤學生在不同程式概念（遞迴、OOP、資料結構）上的理解進度。
- **語言學習**：記住學生常犯的語法錯誤，針對性地提供練習。
- **翻轉教室**：教師透過分析儀表板掌握學生自學狀態，課堂時間聚焦於共同困難點。

### 5.3 測試與品質保證

- **110 個自動化測試**，涵蓋記憶操作、API 端點、LTI 流程、學習分析、匯出匯入。
- **端對端驗證**：已於 Docker Moodle 4 實例完成 LTI 1.3 完整流程（OIDC 登入 → JWT 驗證 → 嵌入對話）。

### 5.4 未來規劃

- **多課程支援**：按課程分隔記憶空間，支援跨課程學習關聯。
- **教師介入機制**：教師可標記/修正 AI 擷取的事實，提升記憶品質。
- **學習預警**：當學生在特定主題的困難持續累積，自動通知教師介入。
- **多語言支援**：AI 自動偵測學生語言，記憶與回應皆支援中英文。

## 六、使用之生成式 AI 說明

本作品使用生成式 AI 作為核心功能元件：

1. **AI 對話回應**：透過大型語言模型（LLM）回答學生的學術問題，回應經記憶上下文增強後更具個人化。
2. **事實自動擷取**：利用 LLM 從對話歷史中自動抽取結構化學習事實（困難點、偏好、進度），免去人工標註。
3. **語意搜尋**：使用嵌入模型（Embedder）將記憶向量化，實現語意層級的記憶檢索。

生成式 AI 在本作品中扮演「理解者」與「擷取者」的雙重角色——不僅回答問題，更主動理解並記住學生的學習狀態，這是本作品的核心創新價值。
