## 評分標準（教育AI組 EDUAI）

### 初賽（書面審查）
| 項目 | 權重 | 對應內容 |
|------|------|---------|
| 創新性 (AI 創新應用、創意、構想) | 40% | 持久記憶機制、自動事實擷取 |
| 技術性 (AI 模型開發、精準度、功能性、穩定性) | 30% | Lite-Mem 引擎、混合搜尋、LTI 1.3、110 測試 |
| 實用性 (可執行度、整合性、使用端接受度) | 30% | Moodle 整合、一鍵部署、開源 |

### 決賽（現場展示 6分鐘 + 問答 7分鐘）
| 項目 | 權重 |
|------|------|
| 創新性 | 35% |
| 技術性 | 25% |
| 實用性 | 25% |
| 說明展示表達能力 | 15% |
