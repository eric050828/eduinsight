# EduInsight — AI 學習助教平台

## 專題簡介

EduInsight 是一個接入 Moodle LMS 的 AI 學習助教平台，以 Lite-Mem 輕量記憶框架為核心，為每位學生建立持久的學習記憶，實現個人化教學輔助與智慧學習分析。

## 要解決的問題

### 學生端痛點
- 課後遇到問題不敢問老師（怕丟臉）
- 每次用 ChatGPT 都要從頭解釋背景
- 不知道自己哪裡弱、該複習什麼
- 期中考前才發現來不及

### 教師端痛點
- 一班 30-40 人，不可能逐一了解學習狀況
- 發現學生有問題時往往已經太晚（期末才知道）
- 無法量化「哪些概念最多人不懂」
- 想關心學生但不知從何下手

### 現有工具的不足
- ChatGPT/Claude：沒有記憶，每次對話重新開始
- Moodle 內建分析：只有成績和登入記錄，看不到學習歷程
- 傳統 AI 教學工具（Squirrel AI、Century Tech）：封閉系統、昂貴、無法接入現有 LMS

## EduInsight 的解決方案

### 核心技術：Lite-Mem 記憶框架
- 自主開發的輕量 AI agent 記憶框架
- BM25 + Embedding 混合搜尋
- 自動萃取學習事實（問題、弱項、偏好）
- 跨 session 持久化，學期越久記憶越豐富

### 學生端功能
1. **AI 學習助教**：記住你的學習歷程，個人化回答
2. **知識維度雷達圖**：一眼看出各主題掌握度
3. **AI 複習建議**：主動推薦你該補強的概念
4. **學習軌跡**：可視化 10 週的進步趨勢（含預測）
5. **課堂即時回饋**：上課中匿名標記「聽不懂」

### 教師端功能
1. **班級健康度總覽**：修課人數、平均成績、風險學生、AI 互動量
2. **成績 vs AI 互動散佈圖**：四象限識別不同類型學生
3. **AI 使用時段熱力圖**：了解全班學習節奏
4. **🚨 預警系統**：自動偵測 at-risk 學生（Persistence Score）
5. **困難概念排行榜**：哪些知識點最多人反覆問
6. **一鍵關懷訊息**：AI 根據學生記憶自動生成個人化訊息

### 設計決策：隱私優先
- 老師看到聚合分析，看不到逐字對話
- 學生的心理安全感 = AI 助教最大價值
- 學生可自願分享特定對話給老師

## Demo 情境

### 設定
- 114 學年度第 2 學期，第 10 週（期中考後）
- 2 位教授、5 位學生、4 門課程
- 模擬已累積 10 週的真實使用資料

### 學生人設
- A 陳同學：認真但基礎弱，期中考 B-，Binary Tree 反覆卡關
- B 林同學：進階生，期中考 A，偶爾問深度問題
- C 王同學：重修生，去年被當，態度消極，期中考 D
- D 李同學：期中考 F，完全消失，疑似考慮二退
- E 張同學：中等程度，期中考 C+，偏好實作

### 展示重點
1. 學生提問 → AI 根據記憶個人化回答（知道他偏好視覺圖解）
2. 教師看到散佈圖，發現 D 李同學在右下角（低成績+零互動）
3. 預警系統自動標記 3 位風險學生
4. 教師一鍵發送 AI 生成的個人化關懷訊息
5. 數據→洞察→行動的完整閉環

## 技術架構

- **記憶層**：Lite-Mem（SQLite + BM25 + Embedding）
- **AI 後端**：Claude Haiku（via claude -p CLI）
- **Web 框架**：FastAPI
- **前端**：純 HTML/CSS/JS + Chart.js
- **LMS 整合**：Moodle REST API + Web Services

## 差異化價值

> 「現有 LMS 只告訴老師『誰考幾分』，EduInsight 告訴老師『誰可能要放棄了、為什麼、怎麼幫他』。」

核心價值：**數據 → 洞察 → 行動** 的完整閉環
1. 數據：AI 助教對話自動萃取學習記憶
2. 洞察：預警系統 + 困難點分析 + 學習偏好
3. 行動：一鍵發送個人化關懷 + AI 推薦複習路徑
